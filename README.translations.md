## English

# Home Assistant website

This is the source for the Home Assistant website.

### Access

You can access the site at the following URLs, depending on the target branch:

- Production (current branch): https://www.home-assistant.io
- Beta (rc branch): https://rc.home-assistant.io
- Development (next branch): https://next.home-assistant.io

Netlify also provides a preview deployment for every pull request.

### Prerequisites

- Ruby (see .ruby-version)
- Bundler
- Node.js (see .nvmrc)
- npm

### Setup and preview

Use the developer documentation for contribution setup.
To preview locally, install dependencies and run:

```bash
bundle exec rake preview
```

### Feature documentation: Language selector in the site navigation

#### Feature name

Header language selector

#### Introduction

The header language selector helps you switch key navigation labels between English, Spanish, and French.

#### Purpose

This feature makes top-level navigation easier to understand for visitors who prefer different languages.

#### Key functions

1. Select a language from the header dropdown.
2. Translate top-level navigation labels.
3. Save your language preference in browser storage.

#### Examples

- Select Spanish in the header to view translated navigation labels.
- Refresh the page and keep your selected language.

#### Conclusion

This feature improves navigation clarity for a broader audience while keeping the user experience simple.

### Documentation de la fonctionnalité: Sélecteur de langue dans la navigation

#### Nom de la fonctionnalité

Sélecteur de langue dans l'en-tête

#### Introduction

Le sélecteur de langue de l'en-tête vous permet de changer les libellés principaux de navigation entre l'anglais, l'espagnol, et le français.

#### Objectif

Cette fonctionnalité rend la navigation plus claire pour les visiteurs qui préfèrent différentes langues.

#### Fonctions clés

1. Sélectionner une langue depuis la liste déroulante de l'en-tête.
2. Traduire les libellés de navigation de premier niveau.
3. Enregistrer la préférence de langue dans le stockage du navigateur.

#### Exemples

- Sélectionnez le français dans l'en-tête pour afficher les libellés traduits.
- Actualisez la page et conservez la langue sélectionnée.

#### Conclusion

Cette fonctionnalité améliore la clarté de navigation pour un public plus large tout en gardant une expérience simple.
