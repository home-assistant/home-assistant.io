## English

# Home Assistant website

This is the source for the Home Assistant website.

### Access

You can access the site at the following URLs, depending on the target branch:

- Production (current branch): https://www.home-assistant.io
- Beta (rc branch): https://rc.home-assistant.io
- Development (next branch): https://next.home-assistant.io

Netlify also provides a preview deployment for every pull request.

### Prerequisites

- Ruby (see .ruby-version)
- Bundler
- Node.js (see .nvmrc)
- npm

### Setup and preview

Use the developer documentation for contribution setup.
To preview locally, install dependencies and run:

```bash
bundle exec rake preview
```
