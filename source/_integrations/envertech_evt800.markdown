The Envertech EVT800 enables {% term integration %} with [Envertech EVT800](https://www.envertec.com/products/microinverter/66.html/) solar inverters in Home Assistant.

## Supported Devices

The following devices are known to be supported by this integration:

- Envertech EVT800

## Prerequisites

Before setting up the integration, ensure the following:

1. Your EVT800 is powered by solar (it does not power on without sunlight).
2. The EVT800 is connected to your local network via Wi-Fi.
3. Determine the **IP address** of the EVT800:
   - Check your router`s device list or use a network scanning tool.
4. Open a web browser and navigate to:
   `http://<YOUR_EVT800_IP_ADDRESS>`
   - Default username: `admin`
   - Default password: `admin`
5. Go to **Other settings** and set the **Protocol** to **TCP Server**.

## Configuration Variables

When you manually add one EVT800 device, the following form is presented:

- **IP Address**: The local IP address of your EVT800 device. Check your router’s device list or use a network scanning tool.
- **Port**: The port where the EVT800 TCP Server is running (default: `14489`).
- **Local Server Type**: Select `TCP Server`. This is currently the only supported protocol for the EVT800 device.

## Sensors

This integration exposes various sensor readings from the Envertech EVT800 inverter.

| `sw_version`      | -    | Firmware version of the inverter.           |
| `input_voltage_1` | V    | Input voltage via MPPT 1.                   |
| `input_voltage_2` | V    | Input voltage via MPPT 2.                   |
| `power_1`         | W    | DC output power via MPPT channel 1.         |

| `current_2`       | A    | Output current on MPPT 2.                   |

## Data Updates

This integration establishes a persistent TCP connection with the EVT800 in **TCP Server mode** and listens for incoming data packets containing the latest sensor values.

## Known Limitations

- The integration does **not** support any actions for the device.
  - To execute any actions on the inverter, use the official EnverBridge or EnverView mobile app.
- Requires sufficient solar input for operation. The inverter is not reachable at night or in low-light conditions.

## Troubleshooting

### Problem: “Data not available”

**Cause**:
Incorrect configuration or the device is not powered.

**Steps to Resolve**:

1. Ensure the EVT800 is receiving enough sunlight to power on.
2. Verify that your Home Assistant instance is on the same local network as the EVT800.
3. Double-check the following:
   - Correct **IP address** and **Port**.
   - **TCP Server mode** is enabled on the inverter.
   - No firewall or router setting is blocking local TCP connections.

---

### General Tips

- If you frequently lose to the device connection, consider assigning a **static IP** to your EVT800 in your router`s DHCP settings.
