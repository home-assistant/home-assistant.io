## Redgtech

The **Redgtech** integration allows you to connect compatible devices with Home Assistant, offering smart control and advanced monitoring.

## *Configuration*

To set up Redgtech integration:

1. *Go to **Settings** > **Devices & Services**.*
2. *Click on **Add Integration**.*
3. *Choose **Redgtech** from the list.*
4. Log in with your Redgtech app credentials.

## Features

- Control smart lights and switches.
- Real-time monitoring.
- Easy and quick setup.

## Supported Devices

| Type         | Model        |
| ------------ | ------------ |
| Smart Switch | Model X1, X2 |
| Smart Bulb   | Model B1, B2 |
