The Legrand Whole House Lighting {% term integration %} is used to integrate with the devices of [Legrand](https://www.legrand.ca/wiring-devices/electrical-accessories/miscellaneous/discontinued-whole-house-lighting-controller/p/lc7001).

You must have configured your system using the Legrand Whole House Lighting [iOS](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://apps.apple.com/ca/app/legrand-lighting-control/id1017835513&ved=2ahUKEwiux_ui37aMAxXqhIkEHdXYMRYQFnoECBsQAQ&usg=AOvVaw1hplo8PYnU9vZ-nLPRroRm) or [Android](https://play.google.com/store/apps/details?id=us.legrand.lighting&hl=en_CA) application.

## Supported devices

The following devices are known to be supported by the integration:

- Lights

## Prerequisites

1. Open the app store and install the **Legrand Lighting Control** app.
2. Set up your system with the app.

## Supported functionality

### Entities

The Legrand Whole House Lighting integration provides the following entities.

#### Lights

The Legrand Whole House Lighting integration exposes the lights and dimmer of your system.

## Troubleshooting

### Can’t set up the device

#### Symptom: “Failed to connect”

When trying to set up the integration, the form shows the message “Failed to connect”.

Verify the host name and port you entered are correct.

If you are running Home Assistant as a container, it may be due to the default hostname (LCM1.local) not being found.
In that case, find out its IP address and use it instead. You should make sure that your network assigns a static IP address to the LC7001 controller.

#### Symptom: "Invalid authentication"

When trying to set up the integration, the form shows the message "Invalid authentication”.

Verify the password you entered is correct.

## Removing the integration

This integration follows standard integration removal.

{% include integrations/remove_device_service.md %}

After deleting the integration, go to the app of the manufacturer and remove the Home Assistant integration from there as well.
