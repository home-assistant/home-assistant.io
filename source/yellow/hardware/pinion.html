Pinion PCB
The Pinion PCB is the carrier board for the Raspberry Pi Compute Module 4 (CM4) that powers Home Assistant Yellow. This open hardware design includes all necessary interfaces and connectivity options for smart home applications.

Pinion PCB Overview

The Pinion PCB serves as the carrier board for the Raspberry Pi Compute Module 4 (CM4) and is the core of the Home Assistant Yellow hardware platform. It provides all the necessary connectivity and expansion options for a complete smart home hub.

Key Features

  • Designed specifically for Raspberry Pi Compute Module 4
  • Direct board-to-board connection for CM4
  • Support for direct boot from NVMe devices
  • Integrated Zigbee/Matter wireless module
  • NVMe M.2 expansion slot
  • Gigabit Ethernet connectivity
  • Multiple USB ports for accessories
  • Audio capabilities
  • Hardware buttons and status LEDs
Hardware Specifications

Dimensions

12 cm x 12 cm carrier board

Power

12V/2A barrel connector (5.5mm x 2.1mm), with PoE+ option

Connectivity

Gigabit Ethernet, Silicon Labs MGM210P for Zigbee/Thread/Matter

Expansion

NVMe M.2 slot (M-Key) supporting 2230, 2242, 2260, 2280 modules

Wireless Module

The integrated Silicon Labs MGM210P Mighty Gecko module provides smart home wireless capabilities:

  • Supports Zigbee 3.0, OpenThread, and Matter protocols
  • 2.4 GHz radio with TX power up to +20 dBm
  • 1024 KB flash memory, 96 KB RAM
  • Pre-installed with Zigbee 3.0 firmware (EZSP)
  • Upgradeable for future protocols
