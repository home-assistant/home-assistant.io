Home Assistant Yellow v1.3 PoE
Hardware documentation for the Power over Ethernet variant of Home Assistant Yellow. This variant includes the Pinion PCB with PoE+ support.

Yellow v1.3 PoE Overview

The Home Assistant Yellow v1.3 PoE variant features the Pinion PCB with Power over Ethernet support, allowing it to be powered through the Ethernet cable. This variant is ideal for installations where a separate power supply is not convenient.

Key Features

  • Power over Ethernet (PoE+) IEEE 802.3at-2009 Class 3 or 4
  • Carrier board for Raspberry Pi Compute Module 4 (CM4)
  • Integrated Zigbee/Matter wireless module
  • NVMe M.2 expansion slot
  • Gigabit Ethernet connectivity
  • Multiple USB ports for accessories
  • Audio capabilities
  • Hardware buttons and status LEDs
Hardware Specifications

Dimensions

12 cm x 12 cm carrier board

Power Options

Either 12V/2A barrel connector OR PoE+ (IEEE 802.3at-2009 Class 3 or 4)

Connectivity

Gigabit Ethernet with PoE support, Silicon Labs MGM210P for Zigbee/Thread/Matter

Expansion

NVMe M.2 slot (M-Key) supporting 2230, 2242, 2260, 2280 modules
