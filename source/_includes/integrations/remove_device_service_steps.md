1. Go to {% my integrations title="**Settings** > **Devices & services**" %} and select the integration card.
2. Next to the entry you want to remove, select the three dots {% icon "mdi:dots-vertical" %} menu. Then, select **Delete**.
   - Depending on the integration, the entries are listed under one of the following headings:
     - **Devices**
     - **Hubs**
     - **Services**
     - **Integration entries**
3. To confirm, select **Delete**.
   - Home Assistant also deletes the devices and entities of the entry.
4. If Home Assistant asks you to restart, [restart Home Assistant](/common-tasks/general/restarting/#restarting-home-assistant).
5. If Home Assistant asks whether to also delete the application credentials, select **Remove** or **Keep**.
   - If you keep them, Home Assistant uses them automatically when you add the integration again.
   - To delete them later, refer to [Deleting application credentials](/integrations/application_credentials/#deleting-application-credentials).
