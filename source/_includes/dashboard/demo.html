{%- comment -%} A live demo of dashboard cards, running against the mocked backend of the Home Assistant demo. The cards come from `demos` in source/_data/dashboard_demos.yml, with the entities and areas they name by their ID from `entities` and `areas` there, and the entities in those areas. Instead of a list of cards, a demo can hold one `section`, `view` or `dashboard`, with its configuration the same as in a dashboard. The page keeps the height from `heights` there for the demo, with a placeholder, so nothing below it moves when the cards load. A dashboard takes that height, and scrolls inside it. source/javascripts/dashboard-demo.js adds the cards from the template once they are in view, so their animations play where they can be seen. {% include dashboard/demo.html demo="feature_toggle" caption="Toggle." %} {%- endcomment -%} {%- assign demo_data = site.data.dashboard_demos -%} {%- assign demo_entry = demo_data.demos[include.demo] -%} {%- assign demo_height = demo_data.heights[include.demo] | default: 56 -%} {%- comment -%} Includes share the variables of the page, so clear the kind of the last demo on it. {%- endcomment -%} {%- assign demo_kind = nil -%} {%- if demo_entry.section -%} {%- assign demo_kind = "section" -%} {%- assign demo_config = demo_entry.section -%} {%- elsif demo_entry.view -%} {%- assign demo_kind = "view" -%} {%- assign demo_config = demo_entry.view -%} {%- elsif demo_entry.dashboard -%} {%- assign demo_kind = "dashboard" -%} {%- assign demo_config = demo_entry.dashboard -%} {%- else -%} {%- assign demo_config = demo_entry -%} {%- endif -%} {%- comment -%} Only the entities and areas the configuration names, to keep the page small, and the entities in those areas. Each ID is matched in quotes in the configuration as JSON, so `light.kitchen` doesn't also bring in `light.kitchen_ceiling`, and IDs in nested options, such as the entities of a glance card or the badges of a heading card, count too. {%- endcomment -%} {%- assign demo_json = demo_config | jsonify -%} {%- assign demo_areas = "" | split: "" -%} {%- for area in demo_data.areas -%} {%- capture demo_quoted_id -%}"{{ area.area_id }}"{%- endcapture -%} {%- if demo_json contains demo_quoted_id -%} {%- assign demo_areas = demo_areas | push: area -%} {%- endif -%} {%- endfor -%} {%- assign demo_area_ids = demo_areas | map: "area_id" -%} {%- assign demo_entities = "" | split: "" -%} {%- for entity in demo_data.entities -%} {%- capture demo_quoted_id -%}"{{ entity.entity_id }}"{%- endcapture -%} {%- if demo_json contains demo_quoted_id or demo_area_ids contains entity.area_id -%} {%- assign demo_entities = demo_entities | push: entity -%} {%- endif -%} {%- endfor -%} {%- capture demo_home -%} {"entities": {{ demo_entities | jsonify }}, "areas": {{ demo_areas | jsonify }}} {%- endcapture -%}
