{%- comment -%} The blog's filters: the active filters, each removable on its own, and a Filters button that opens a drawer with every category, year and author. The drawer's lists show what each choice gives from this page, so a category's years, or a year's categories, combine the two. The drawer is a side panel on wider screens and a bottom sheet on phones. Every filter is a link to a static page, so filtering works without JavaScript. The drawer opens with invoker commands (commandfor), with a small script for browsers that don't support them yet. See plugins/blog_listings.rb for page.listing. {%- endcomment -%} {%- assign listing = page.listing -%} {%- assign drawer = listing.drawer -%}
