With this action, you can update a Z-Wave device parameter through the ISY. The new value is also returned as an entity attribute named `ZW#`, where `#` is the parameter number.

{% include actions/ui_header.md %}

To use this action in an automation or script:

1. Go to {% my automations title="**Settings** > **Automations & scenes**" %}.
2. Open an existing automation or script, or select **Create** to start a new one.
3. If you're setting up a new automation, add a trigger in the **When** section. Scripts don't need a trigger.
4. In the **Then do** section, select **Add action**.
5. Select what you want to control. Under **By target** (see [Targets](#targets)), select the ISY Z-Wave entity you want to update.
6. From the actions shown for that target, select **ISY: Set Z-Wave parameter**.
7. Enter the **Parameter** number, the **Value**, and the **Size**.
8. Select **Save**.

### Options in the UI

{% options_ui %}
Parameter:
  description: The parameter number to set on the device.
Value:
  description: The value to set for the parameter.
Size:
  description: The size of the parameter in bytes. One of 1, 2, or 4.
{% endoptions_ui %}

{% include actions/yaml_header.md %}

In YAML, refer to this action as `isy994.set_zwave_parameter`. A basic example looks like this:

{% example %}
action: |
  action: isy994.set_zwave_parameter
  target:
    entity_id: switch.garage_door
  data:
    parameter: 8
    value: 33491663
    size: 4
{% endexample %}

This sets parameter 8 to `33491663` on the `switch.garage_door` Z-Wave device.

### Options in YAML

{% options_yaml %}
parameter:
  description: The parameter number to set on the device.
  required: true
  type: integer
value:
  description: The value to set for the parameter.
  required: true
  type: integer
size:
  description: The size of the parameter in bytes. One of 1, 2, or 4.
  required: true
  type: integer
{% endoptions_yaml %}

## Targets of the action

This action requires a target. The target is the object of the action. You can point the action at a single {% term entity %}, a device, an area, a floor, or a label, and Home Assistant runs the action on every matching ISY entity behind that target. The entity must be an ISY Z-Wave node.

- **Entity**: one specific ISY Z-Wave entity, such as `switch.garage_door`.
- **Device**: every ISY Z-Wave entity that belongs to a device.
- **Area**: every ISY Z-Wave entity in a room or area.
- **Floor**: every ISY Z-Wave entity on a floor.
- **Label**: every ISY Z-Wave entity that shares a label.

You can also select different target types in one action. For example, you can add a specific entity and an area as targets in the same action to run the action on both of them at once.
