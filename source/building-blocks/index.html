Building blocks control how the actions of an automation or a script run. For example, they wait, repeat steps, or choose between steps. In the editor, you find them under Blocks when you add an action.

Browse the list below, or use the search box to find a building block by name or description. For an introduction, refer to Building blocks in automations and scripts.
