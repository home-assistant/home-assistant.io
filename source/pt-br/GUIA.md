# Guia da Documentação do Home Assistant em Português do Brasil

Bem-vindo à documentação do Home Assistant em português do Brasil!

Este é um esforço da comunidade para traduzir a documentação oficial do Home Assistant para o português do Brasil. O objetivo é tornar o Home Assistant mais acessível para a comunidade de língua portuguesa.

## Navegando pela Documentação

A estrutura da documentação traduzida é a mesma da documentação original em inglês. Você pode navegar pela documentação usando a barra lateral à esquerda.

A documentação está dividida em várias seções, incluindo:

- **Começando:** Se você é novo no Home Assistant, esta é uma ótima seção para começar. Ela aborda os conceitos básicos de como configurar e usar o Home Assistant.
- **Configuração:** Esta seção aborda como configurar os vários aspectos do Home Assistant, incluindo integrações, automações e scripts.
- **Integrações:** Esta seção fornece documentação para todas as integrações disponíveis no Home Assistant.
- **Automação:** Esta seção aborda como criar automações no Home Assistant.
- **Lovelace:** Esta seção aborda como criar painéis personalizados usando a interface do usuário Lovelace.
