---
title: "Frontend do Home Assistant"
description: "Uma visão geral do frontend do Home Assistant."
---

O frontend do Home Assistant é a interface do usuário que você usa para interagir com seu sistema Home Assistant. É uma aplicação web que roda em seu navegador e se comunica com o backend do Home Assistant para exibir informações e enviar comandos.

## O Painel

A tela principal do frontend é o painel. O painel é uma coleção de cartões que exibem informações sobre seus dispositivos e entidades. Você pode personalizar o painel para exibir as informações mais importantes para você.

## A Barra Lateral

A barra lateral à esquerda do painel fornece acesso a outras partes do frontend. A partir daqui, você pode navegar para:

- **Mapa:** Uma visualização de mapa de seus dispositivos e entidades.
- **Logbook:** Um registro de todos os eventos que ocorreram em seu sistema Home Assistant.
- **Histórico:** Gráficos do histórico de seus dispositivos e entidades.
- **Ferramentas do Desenvolvedor:** Uma coleção de ferramentas para desenvolvedores, incluindo um visualizador de eventos e um testador de modelos.
- **Configuração:** A seção de configuração do Home Assistant, onde você pode gerenciar suas integrações, dispositivos e entidades.

## Temas

Você pode personalizar a aparência do frontend usando temas. Os temas permitem que você altere as cores, fontes e outros aspectos visuais do frontend.

Existem muitos temas criados pela comunidade que você pode usar, ou você pode criar seu próprio tema.

## Lovelace

O frontend do Home Assistant é construído sobre uma estrutura chamada Lovelace. Lovelace é uma estrutura poderosa e flexível que permite criar painéis personalizados com uma ampla variedade de cartões.

Você pode configurar seus painéis Lovelace usando a interface do usuário ou editando o arquivo de configuração `ui-lovelace.yaml`.

## Desempenho

O frontend do Home Assistant é projetado para ser rápido e responsivo. Ele usa uma variedade de técnicas para otimizar o desempenho, incluindo cache e carregamento lento.

Se você estiver enfrentando problemas de desempenho com o frontend, existem várias coisas que você pode tentar para melhorar as coisas, como desabilitar animações e reduzir o número de cartões em seus painéis.
