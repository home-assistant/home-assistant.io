---
title: "Categorias"
description: "Como usar categorias para organizar seus itens."
---

As categorias no Home Assistant permitem que você agrupe itens em tabelas, como automações, cenas e scripts. Isso pode tornar mais fácil encontrar e gerenciar seus itens.

## Criando uma categoria

Você pode criar categorias na página de configurações do item que deseja categorizar. Por exemplo, para criar uma categoria para suas automações, vá para a página "Automações & Cenas" e clique no botão "Categorias".

A partir daqui, você pode criar novas categorias e atribuir suas automações a elas.

## Usando categorias

Depois de criar categorias, você pode usá-las para filtrar seus itens. Por exemplo, você pode filtrar sua lista de automações para mostrar apenas as automações em uma categoria específica.

Você também pode usar categorias para organizar seus itens em diferentes visualizações. Por exemplo, você pode criar uma visualização que mostra todas as suas automações de iluminação e outra visualização que mostra todas as suas automações de segurança.

## Categorias vs. Rótulos

Categorias e rótulos são semelhantes, pois ambos permitem que você agrupe seus itens. No entanto, existem algumas diferenças importantes.

As categorias são exclusivas para cada tabela. Por exemplo, as categorias para automações são diferentes das categorias para cenas.

Os rótulos, por outro lado, podem ser aplicados a qualquer tipo de item, incluindo áreas, dispositivos, entidades, automações, cenas e scripts.

As categorias são melhores para organizar itens dentro de uma tabela específica, enquanto os rótulos são melhores para agrupar itens relacionados de diferentes tipos.
