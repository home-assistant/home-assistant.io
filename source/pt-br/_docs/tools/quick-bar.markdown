A barra rápida é um recurso no Home Assistant que permite navegar e controlar rapidamente sua instância. Você pode acessá-la pressionando `c` em qualquer lugar na interface do usuário.

## Usando a barra rápida

Quando você abre a barra rápida, você verá uma barra de pesquisa. Você pode começar a digitar para pesquisar entidades, dispositivos, automações, scripts e muito mais.

Os resultados da pesquisa serão exibidos abaixo da barra de pesquisa. Você pode usar as teclas de seta para navegar pelos resultados e pressionar Enter para selecionar um resultado.

## Comandos

Além de pesquisar, você também pode usar a barra rápida para executar comandos. Para executar um comando, digite `>` seguido do comando.

Existem vários comandos disponíveis, incluindo:

- **> recarregar:** Recarrega sua configuração.
- **> reiniciar:** Reinicia o Home Assistant.
- **> parar:** Para o Home Assistant.
- **> atualizar:** Verifica se há atualizações.

Você também pode criar seus próprios comandos personalizados.

## Navegação

A barra rápida também pode ser usada para navegar para diferentes partes do Home Assistant. Por exemplo, você pode digitar "configuração" para ir para a página de configuração, ou "ferramentas do desenvolvedor" para ir para as ferramentas do desenvolvedor.

## Dicas e truques

- Você pode usar o atalho do teclado `Ctrl+K` ou `Cmd+K` para abrir a barra rápida.
- Você pode usar as teclas de seta para navegar pelos resultados da pesquisa.
- Você pode pressionar Enter para selecionar um resultado.
- Você pode pressionar Esc para fechar a barra rápida.
