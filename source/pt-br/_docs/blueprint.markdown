Os Blueprints de Automação são um recurso do Home Assistant que permite que você compartilhe e use facilmente automações pré-fabricadas.

## O que é um blueprint?

Um blueprint é um modelo para uma automação. Ele define a lógica da automação, mas permite que você personalize os dispositivos e entidades que são usados.

Por exemplo, você pode ter um blueprint que liga uma luz quando o movimento é detectado. O blueprint define a lógica para isso, mas permite que você escolha qual sensor de movimento e qual luz usar.

## Onde encontrar blueprints?

Você pode encontrar blueprints no Fórum do Home Assistant e no GitHub. A comunidade do Home Assistant criou muitos blueprints úteis que você pode usar em seu próprio sistema.

## Como usar um blueprint?

Para usar um blueprint, você primeiro precisa importá-lo para sua instância do Home Assistant. Você pode fazer isso navegando para a seção de blueprints em sua configuração do Home Assistant e clicando no botão "Importar Blueprint".

Depois de importar um blueprint, você pode criar uma automação a partir dele. A interface do usuário irá guiá-lo através do processo de configuração da automação, permitindo que você escolha os dispositivos e entidades a serem usados.

## Como criar um blueprint?

Você também pode criar seus próprios blueprints para compartilhar com a comunidade. Para fazer isso, você precisará criar um arquivo YAML que defina a lógica da automação.

A documentação do Home Assistant tem um guia detalhado sobre como criar blueprints.
