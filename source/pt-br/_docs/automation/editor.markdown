---
title: "Editor de Automação"
description: "Como usar o editor de automação para criar e editar automações."
---

O editor de automação é uma ferramenta na interface do usuário do Home Assistant que permite criar e editar automações sem precisar escrever YAML.

## Criando uma automação

Para criar uma nova automação, vá para a seção de configuração do Home Assistant e clique no botão "Automações & Cenas". A partir daqui, você pode clicar no botão "Adicionar Automação" para iniciar o editor de automação.

O editor de automação irá guiá-lo através do processo de criação de uma automação, permitindo que você especifique o gatilho, a condição e a ação.

## Editando uma automação

Para editar uma automação existente, encontre-a na lista de automações e clique nela. Isso abrirá o editor de automação, onde você poderá fazer alterações na automação.

## Usando o editor de YAML

O editor de automação também inclui um editor de YAML que você pode usar para editar o YAML de suas automações diretamente. Isso é útil se você preferir escrever YAML ou se precisar usar recursos avançados que não são suportados pelo editor visual.

Para acessar o editor de YAML, clique no ícone de três pontos no canto superior direito do editor de automação e selecione "Editar como YAML".

## Desativando uma automação

Você pode desativar uma automação no editor de automação. Isso evitará que a automação seja executada até que você a ative novamente.

Para desativar uma automação, clique no botão de alternância ao lado do nome da automação na lista de automações.

## Excluindo uma automação

Você pode excluir uma automação no editor de automação. Isso removerá permanentemente a automação do seu sistema.

Para excluir uma automação, clique no ícone de três pontos no canto superior direito do editor de automação e selecione "Excluir".
