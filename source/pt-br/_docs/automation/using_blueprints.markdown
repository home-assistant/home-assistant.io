---
title: "Usando Blueprints de Automação"
description: "Como usar blueprints para criar automações facilmente."
---

Os blueprints de automação são uma ótima maneira de começar com automações no Home Assistant. Eles são automações pré-fabricadas que você pode importar e usar com o mínimo de configuração.

## Encontrando blueprints

Você pode encontrar blueprints no Fórum do Home Assistant e no GitHub. A comunidade do Home Assistant criou muitos blueprints úteis que você pode usar em seu próprio sistema.

## Importando um blueprint

Para usar um blueprint, você primeiro precisa importá-lo para sua instância do Home Assistant. Você pode fazer isso navegando para a seção de blueprints em sua configuração do Home Assistant e clicando no botão "Importar Blueprint".

Você precisará fornecer o URL do blueprint que deseja importar. Depois de importar um blueprint, ele estará disponível para você usar ao criar novas automações.

## Criando uma automação a partir de um blueprint

Depois de importar um blueprint, você pode criar uma automação a partir dele. Para fazer isso, vá para a seção "Automações & Cenas" de sua configuração e clique no botão "Adicionar Automação".

Você será solicitado a escolher um blueprint para usar. Depois de selecionar um blueprint, você será solicitado a preencher quaisquer entradas necessárias. As entradas são os valores configuráveis no blueprint, como os dispositivos e entidades a serem usados.

Depois de preencher as entradas, você pode salvar a automação. A automação será executada com base na lógica definida no blueprint.

## Vantagens de usar blueprints

Existem várias vantagens em usar blueprints:

- **Fácil de usar:** Os blueprints são uma ótima maneira de começar com automações, mesmo que você não tenha nenhuma experiência anterior.
- **Economia de tempo:** Os blueprints podem economizar muito tempo, fornecendo automações pré-fabricadas que você pode usar com o mínimo de configuração.
- **Compartilhável:** Os blueprints podem ser facilmente compartilhados com outras pessoas, para que você possa se beneficiar do trabalho de outros na comunidade do Home Assistant.
- **Atualizável:** Se o autor de um blueprint o atualizar, você pode atualizar facilmente suas automações para usar a versão mais recente.

## Criando seus próprios blueprints

Se você não conseguir encontrar um blueprint que atenda às suas necessidades, você pode criar o seu próprio. Criar blueprints é mais avançado, mas permite que você crie automações reutilizáveis que você pode compartilhar com a comunidade.

A documentação do Home Assistant tem um guia detalhado sobre como criar blueprints.
