Esta página contém um glossário de termos comumente usados no Home Assistant.

## Ação

Uma ação é uma tarefa que o Home Assistant executa quando uma automação é acionada. Por exemplo, uma ação pode ser ligar uma luz, enviar uma notificação ou ajustar um termostato.

## Automação

Uma automação é uma regra que o Home Assistant segue para automatizar seu sistema. As automações consistem em um gatilho, uma condição e uma ação.

## Blueprint

Um blueprint é um modelo para uma automação. Ele define a lógica da automação, mas permite que você personalize os dispositivos e entidades que são usados.

## Componente

Um componente é um pedaço de código que adiciona funcionalidade ao Home Assistant. Os componentes podem adicionar suporte para novos dispositivos, serviços ou integrações.

## Condição

Uma condição é um teste que o Home-Assistant executa antes de executar a ação de uma automação. Se a condição for verdadeira, a ação será executada. Se a condição for falsa, a ação não será executada.

## Dispositivo

Um dispositivo é um pedaço de hardware que está conectado ao Home Assistant, como uma luz, interruptor, sensor ou termostato.

## Entidade

Uma entidade é uma representação de um dispositivo ou serviço no Home Assistant. As entidades têm um estado e atributos que descrevem o estado atual do dispositivo ou serviço.

## Evento

Um evento é algo que acontece no Home Assistant, como o acionamento de um sensor ou o ligar de um interruptor. Os eventos podem ser usados para acionar automações.

## Integração

Uma integração é uma conexão entre o Home Assistant e outro dispositivo ou serviço. As integrações permitem que o Home Assistant se comunique com outros dispositivos e serviços e os controle.

## Lovelace

Lovelace é a estrutura da interface do usuário do Home Assistant. Lovelace é uma estrutura poderosa e flexível que permite criar painéis personalizados com uma ampla variedade de cartões.

## Cena

Uma cena é um conjunto de estados de entidade que você pode salvar e restaurar. As cenas são úteis para criar diferentes modos de iluminação ou para definir sua casa em um estado específico.

## Script

Um script é uma sequência de ações que você pode executar sob demanda. Os scripts são úteis para criar automações complexas ou para executar uma série de ações com um único clique.

## Serviço

Um serviço é uma função que um componente do Home Assistant expõe. Os serviços podem ser chamados a partir de automações, scripts ou da interface do usuário.

## Estado

O estado de uma entidade é o valor atual da entidade. Por exemplo, o estado de uma entidade de luz pode ser "ligado" ou "desligado".

## Gatilho

Um gatilho é um evento que inicia uma automação. Por exemplo, um gatilho pode ser o acionamento de um sensor de movimento, o pressionamento de um botão ou uma hora específica do dia.
