Home Assistant runs on hardware in your home, so your data stays there unless you decide otherwise. You can run it on a computer you already own, or start with official Home Assistant hardware that works out of the box. Nabu Casa makes official Home Assistant products, and every one is built to work with Home Assistant from the moment you plug it in.

Start here

Run Home Assistant with a hub

A hub is the device Home Assistant runs on. Home Assistant Green comes with Home Assistant Operating System already installed. Connect power and your network, and you're up and running.

Home Assistant Green

The easiest way to get started with Home Assistant

  • Home Assistant already installed
  • No assembly or flashing required
  • Set up from your phone or computer, no monitor or keyboard needed

Connect more devices

Add Zigbee, Thread, and Z-Wave

Many smart home devices talk over low-power wireless standards instead of Wi-Fi. A Home Assistant Connect adapter plugs into your hub over USB and lets Home Assistant control those devices directly, from any brand that supports the standard.

Home Assistant Connect ZBT-2

The easiest way to start with Zigbee or Thread

  • Connect Zigbee devices, or Thread devices such as Matter over Thread
  • Plugs into your hub with a USB-C cable
Get Connect ZBT-2 {% include assets/chevron_right.html %}

Home Assistant Connect ZWA-2

Add voice

Control your home with your voice

Assist is the voice assistant built into Home Assistant. Home Assistant Voice Preview Edition gives Assist a speaker and microphones, so you can control your home by talking to it.

Use hardware you already have

You don't need official hardware to run Home Assistant. You can install it on a Raspberry Pi, an Odroid, an x86-64 computer, or in a container or virtual machine. See the installation page to pick the option that fits you best.
