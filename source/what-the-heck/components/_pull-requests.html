{%- comment -%} The pull requests that fix a WTH, as a sea of cards drifting along the same pipes as the WTHs in "What is a WTH". The pull requests and the counts come from `rake wth_stats_data`, which the build runs first. Without them (a local build, or GitHub did not answer) nothing is rendered. Four lanes on the four pipes in _sea-background.html, as in _what.html. Each lane holds its run twice, so it loops without a seam. A run has at least four cards, so it is wider than the sea even when there are only a few pull requests; the cards that fill it up are copies, like the second run. The first run of each lane is the list of pull requests that keyboards and screen readers get, one link each. Everything else is aria-hidden and out of the tab order. It is paused while the pointer or focus is inside it, as the sea of WTHs is, and played by /javascripts/wth/wth-prs.js.
